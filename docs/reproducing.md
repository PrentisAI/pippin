# Reproducing the paper

The `experiments/` directory of the repository contains the evaluations
reported in the paper, with the released data (labels, test sets, model
outputs) and commands that recompute every reported number offline, without
API calls. Re-running the models is possible too; each experiment's README
gives the command and the expected cost.

See [experiments/README.md](https://github.com/titanresearchlabs/aurora/tree/main/experiments).
