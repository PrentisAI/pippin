# Changelog

## 0.1.0

First public release.

- Campaign pipeline: multi-agent ideation (roundtable or independent selection),
  screening, planning, research, analysis with follow-up rounds, writing.
- Milestone auditor (pass / reject / escalate) and live auditor
  (continue / advise / interrupt / escalate).
- Human gates, supervised and autonomous modes, front desk agent for duplex
  interaction.
- One Docker container per campaign; Claude Code sessions confined to the
  campaign directory.
- Skill library with human-written and distilled skills.
- Budgets, checkpoints and resume.
- `aurora` CLI and web console; offline mock mode and demo.
- Scripts and data to reproduce the paper's evaluations.
